# Настройки web-аутентификации для запуска

Параметры задаются через переменные окружения. При запуске через Docker Compose
заполните `.env` в корне проекта; образец переменных находится в `.env_dist`.
При запуске из IDE или через Java передайте переменные в окружение процесса.

## Обязательная настройка JWT

Задайте `WEB_AUTH_JWT_SECRET_BASE64` — ключ подписи JWT в Base64, содержащий
как минимум 32 случайных байта. Сгенерировать ключ можно командой:

```sh
openssl rand -base64 32
```

Сохраните результат в `.env` или окружении сервера. Используйте один и тот же ключ
после перезапуска приложения. Без ключа, с некорректным Base64 или слишком коротким
ключом приложение не запустится.

Дополнительные параметры JWT можно оставить со значениями по умолчанию:

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `WEB_AUTH_ISSUER` | Идентификатор издателя токенов | `config-shop` |
| `WEB_AUTH_AUDIENCE` | Идентификатор API, для которого выпускаются токены | `config-shop-web-api` |

## Отправка писем подтверждения

Для регистрации с подтверждением почты настройте SMTP и адрес страницы подтверждения:

| Переменная | Что указать |
|---|---|
| `SPRING_MAIL_HOST` | Адрес SMTP-сервера почтового провайдера |
| `SPRING_MAIL_PORT` | Порт SMTP-сервера; обычно `587` для STARTTLS |
| `SPRING_MAIL_USERNAME` | Имя пользователя для авторизации на SMTP-сервере |
| `SPRING_MAIL_PASSWORD` | Пароль SMTP или пароль приложения, выданный провайдером |
| `WEB_AUTH_MAIL_FROM` | Адрес отправителя, разрешённый почтовым провайдером |
| `WEB_AUTH_CONFIRMATION_URL` | Полный HTTP/HTTPS URL страницы подтверждения почты, например `https://example.com/confirm-email`, без фрагмента `#...` |
| `SMTP_AUTH` | Авторизация на SMTP-сервере; по умолчанию `true` |
| `SMTP_STARTTLS` | Использование STARTTLS; по умолчанию `true` |

Для локального SMTP без авторизации задайте `SMTP_AUTH=false` и
`SMTP_STARTTLS=false`; имя пользователя и пароль можно не указывать.

Таймауты подключения, чтения и записи SMTP заданы в `application.properties`
и составляют по 5 секунд.

Без настроек SMTP, отправителя или страницы подтверждения приложение запускается,
но отправка писем недоступна.

## Сброс пароля и привязка Telegram

| Переменная | Что указать |
|---|---|
| `WEB_AUTH_PASSWORD_RESET_URL` | URL страницы установки нового пароля, например `https://example.com/reset-password` |

Указывайте адреса страниц без фрагмента `#...`. Для браузера разместите сайт и
API на одном HTTPS-адресе, чтобы браузер отправлял защищённую refresh-cookie.
Если используется Telegram webhook, прокси должен передавать приложению заголовок
`X-Telegram-Bot-Api-Secret-Token`. Приложение регистрирует его в Telegram при
запуске на основе действующего `TELEGRAM_BOT_TOKEN`.

Страница `/link-telegram.html` доступна по адресу приложения. Войдите под
подтверждённым веб-профилем, чтобы получить шестизначный код на 5 минут.
Введите код в личном чате с ботом через кнопку «Подключить сайт».
