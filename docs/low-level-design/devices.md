# Изменение количества устройств

## High level

1. Пользователь выбирает новое количество устройств от `MIN_DEVICE_COUNT` до `MAX_DEVICE_COUNT`.
2. Изменение оплачивается оставшимся временем подписки, без отдельного денежного платежа.
3. Остаток пересчитывается с точностью до секунды, после чего новое ограничение устройств и срок передаются в Remnawave.
4. При продлении на другое количество устройств сначала пересчитывается старый остаток, затем прибавляется купленный срок.

Перед подтверждением пользователь должен увидеть результат пересчета.

## Config

Тариф задается четырьмя крайними точками: 1 и 12 месяцев для минимального и максимального количества устройств.

```properties
MIN_DEVICE_COUNT=3
MAX_DEVICE_COUNT=10

BASE_PRICE_FOR_1_MONTH=179
BASE_PRICE_FOR_12_MONTH=1200

EXTRA_PER_DEVICE_1_MONTH=50
EXTRA_PER_DEVICE_12_MONTH=200

DEVICE_CHANGE_VALUE_RETENTION=0.95
```

## Расчет стоимости

Для `d` устройств сначала рассчитываются цены крайних сроков:

```text
price1(d)  = BASE_PRICE_FOR_1_MONTH
             + (d - MIN_DEVICE_COUNT) * EXTRA_PER_DEVICE_1_MONTH

price12(d) = BASE_PRICE_FOR_12_MONTH
             + (d - MIN_DEVICE_COUNT) * EXTRA_PER_DEVICE_12_MONTH
```

Для срока `m` месяцев от 1 до 12 используется степенная интерполяция:

```text
beta = log(price12 / price1) / log(12)
price(m) = price1 * m^beta
```

Она проходит через обе крайние точки. Полная стоимость растет вместе со сроком, а стоимость одного дня уменьшается.

- Для срока меньше месяца используется цена дня месячного тарифа: `price = price1 * m`.
- Для срока больше 12 месяцев используется цена дня годового тарифа: `price = price12 * m / 12`.
- Ограничивается цена дня, а не продолжительность: остаток в 10 дней не должен оцениваться как полный месяц.

## Пересчет устройств

Используются две взаимно обратные операции:

```text
valueOf(devices: Int, duration: Duration): Double
durationOf(devices: Int, value: Double): Duration
```

```text
newDuration = durationOf(
    newDevices,
    valueOf(oldDevices, remainingDuration) * DEVICE_CHANGE_VALUE_RETENTION
)
```

Результат `durationOf` округляется вниз до целой секунды. Коэффициент `0.95` сохраняет 95% тарифной стоимости остатка, поэтому каждая смена количества устройств уменьшает его ценность на 5% в обоих направлениях.

Если подписка истекла, старый остаток считается равным нулю.

## Валидация конфигурации

Для минимального и максимального количества устройств должны выполняться условия:

```text
price12 > price1
price12 < price1 * 12
```

Первое гарантирует рост полной стоимости со сроком, второе — снижение стоимости одного дня.
